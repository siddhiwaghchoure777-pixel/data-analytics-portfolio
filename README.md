Sales and Profit Dashboard

📊 Project Overview

This project presents an interactive Sales and Profit Dashboard created in Microsoft Excel to analyze business performance and make key metrics easier to understand through data visualization.

The dashboard provides a visual overview of sales and profitability and helps identify patterns and trends in the underlying data.

🎯 Objectives

- Analyze sales and profit performance
- Transform raw data into meaningful visual insights
- Create an interactive and easy-to-understand dashboard
- Present key business metrics using Excel visualizations

🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Data Visualization
- Dashboard Design
- Charts & Interactive Filters
